# AlgoHub · 算法学习中心

> 算法学习一站式平台：汇集主流刷题平台、优质学习资源与讲解视频，搭配错题本与进度追踪，助你系统化攻克算法与数据结构。

## ✨ 功能特性

### 核心功能

- **刷题平台导航**：收录 LeetCode、Codeforces、洛谷、AcWing、牛客、AtCoder 等 10 个主流平台，支持搜索与标签筛选
- **学习资源**：OI Wiki、CP-Algorithms、代码随想录、Hello 算法、VisuAlgo 等 12 个优质资源，按文档/书籍/工具/仓库分类
- **视频教程**：12 个精选视频（MIT 算法导论、代码随想录、董晓算法等），覆盖基础到进阶
- **错题本**：完整增删改查，每道错题记录题目链接、来源平台、难度、算法分类、错题原因、自己的代码、最优解法、备注；代码块支持一键复制；数据持久化到 localStorage

### 扩展功能

- 算法知识图谱（12 个专题分类导航，点击跳转对应错题）
- 学习进度追踪（各专题掌握度进度条，点击调整）
- 每日打卡 + 连续打卡天数统计 + 28 天打卡日历
- 首页学习概览统计面板
- 深色 / 亮色主题切换
- 全局搜索 + 分类筛选
- 数据导出为 JSON 备份文件
- Toast 提示、ESC 关闭弹窗、响应式布局

## 🎨 设计风格

科技感深色主题：动态网格背景 + 霓虹青紫渐变 + 浮动光斑 + 玻璃态卡片 + 发光悬停效果 + 等宽字体代码块。

## 🛠️ 技术栈

| 类别 | 技术 |
|------|------|
| 结构 | HTML5 单页应用 |
| 样式 | 原生 CSS3（CSS 变量、backdrop-filter、动画） |
| 逻辑 | 原生 JavaScript（ES6+，IIFE 模块） |

## 🚀 快速开始

直接双击 `index.html` 在浏览器中打开即可使用，无需任何构建工具或服务器。

## 📖 使用说明

- **刷题平台 / 学习资源 / 视频**：点击卡片上的「前往」按钮跳转对应平台
- **错题本**：点击「添加错题」填写表单，支持展开查看自己的代码与最优解法对比
- **学习进度**：点击进度条调整掌握度，每日打卡记录学习连续性
- **主题切换**：右上角月亮/太阳图标切换深色/亮色
- **数据导出**：右上角保存图标导出 JSON 备份

## 📝 错题本字段说明

| 字段 | 说明 |
|------|------|
| 题目标题 | 必填，如「两数之和 / LeetCode 1」 |
| 题目链接 | 必填，原题 URL |
| 来源平台 | LeetCode / Codeforces / 洛谷 等 |
| 难度 | 简单 / 中等 / 困难 |
| 算法分类 | 数组 / 链表 / 动态规划 等 14 类 |
| 错题原因 | 必填，详细描述出错原因 |
| 自己的代码 | 提交的代码（可选） |
| 最优解法 | 参考最优解（可选） |
| 备注 | 补充说明（可选） |
